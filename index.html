ConfiQuiz 🧠

This is a quiz game that tests not only whether you're correct, but also how confident you are. For each multiple-choice question, distribute 100% probability among the four answers.

The score for each question is based on −ln(pcorrect), inspired by KL Divergence. Lower scores indicate better calibration — a perfect score (0.000) means you were 100% confident and correct.

Based on this post by Vincent Vanhoucke.
